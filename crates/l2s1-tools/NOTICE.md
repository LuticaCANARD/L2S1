The Rust JevBench public scorer and summary follow the reviewed JevBench revision `f79a1cab94ab9a5879383b7ef9ee1805b9dc2d84`. JevBench is Copyright (c) 2026 Florian Standhartinger and contributors, MIT licensed; see [JEVBENCH_LICENSE](JEVBENCH_LICENSE). The Rust implementation was independently transcribed and checked against saved public results. It does not implement the complete official leaderboard score.

`src/laya_probes.json` is a rendering of nine public behavioural probe cases from `Luni/laya-jev-benchmark` revision `d75081b2a4b2ad772793d6a7f5f5b4fdca00d557`. The CLI checks the fetched `bench/probe.py` SHA256 before using this rendering. The original source and dataset terms remain applicable. Other full benchmark datasets and model weights are not included in this crate.
