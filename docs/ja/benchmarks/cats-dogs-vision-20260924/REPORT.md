このディレクトリには、要約 JSON ファイル、画像ごとの観察記録、および履歴 `evaluate-order-check.py` 評価器の両方が含まれています。ソース イメージ アーカイブとサーバー ログはローカルに残ります。画像バイトやモデルの重みは公開されません。評価者は、記録されたバイナリによって受け入れられる `image_base64` フィールドを送信します。現在の L2S1 HTTP リリースは、バージョン化された `media` リクエスト コントラクトを使用するため、スクリプトは現在の `main` に対して再生する前にリクエスト形状の更新が必要です。上記のバイナリ SHA-256 は、これらの結果を生成したバージョンを識別します。 GPU プロセスは実行のたびに停止されました。
