이 디렉토리는 요약 JSON 두 개와 이미지별 관찰 기록을 보존합니다. 과거 평가기는 현재 규약에서 지원하지 않는 `image_base64`를 사용하므로 삭제했습니다. 기록된 바이너리에 대응하는 [당시 소스](https://github.com/LuticaCANARD/L2S1/blob/eb900059b7eb93f19c9502a50eeb729d7224e240/benchmarks/cats-dogs-vision-20260924/evaluate-order-check.py)는 Git 이력에서 확인할 수 있습니다. 현재 L2S1은 버전이 지정된 `media` 규약을 사용합니다. 원본 이미지와 서버 로그는 로컬에 남으며 이미지 바이트·모델 가중치는 공개하지 않습니다. 위의 바이너리 SHA-256은 결과를 만든 버전을 식별합니다.
